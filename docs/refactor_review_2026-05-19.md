## Кроссплатформенность

| Среда | Оценка запуска | Комментарий |
|---|---|---|
| macOS | Работает сейчас | Нужны Python 3.11+, SNAP `gpt`, SNAPHU, GDAL/rasterio, PyTorch |
| Linux | Реалистично и желательно для воспроизводимости | Shell-скрипты, SNAP, SNAPHU, GDAL и PyTorch хорошо ложатся на Linux; это лучший вариант для серверного запуска |
| Windows без WSL | Проблемно | Bash-скрипты, SNAPHU, SNAP CLI и GDAL-зависимости потребуют отдельной адаптации под PowerShell/Conda |
| Windows через WSL2 | Реалистично | Можно запускать почти как на Linux, но пути к внешним дискам и GUI-компоненты SNAP нужно настроить отдельно |
| Docker/Devcontainer | Желательно для финальной универсальности | Позволит зафиксировать Python, GDAL, зависимости и команды; SNAP/SNAPHU нужно аккуратно добавить в образ |
