# Инвентаризация дерева проекта для рефакторинга

Дата актуализации: 2026-05-19.

Документ фиксирует назначение файлов и каталогов после перехода проекта к единому пайплайну `src/dem`, InSAR-обработке, ML-коррекции остаточной ошибки и формированию итоговых артефактов для ВКР.

В инвентаризацию не включены содержимое `.git/`, `.venv/`, кэши Python, большие локальные данные `data/raw`, `data/processed`, `outputs`, обученные модели и сгенерированные GeoTIFF/PNG/HTML. Эти данные должны храниться локально или во внешнем хранилище и не попадать в Git.

## Локальные артефакты, которые не должны попадать в Git

| Тип | Примеры | Причина |
|---|---|---|
| Сырые данные | `data/raw/*.zip`, `*.SAFE/`, SLC-архивы | очень большой объём, внешние исходные данные |
| Подготовленные растры | `data/processed/**/*.tif`, `outputs/**/*.tif` | воспроизводимые результаты пайплайна |
| SNAP/SNAPHU продукты | `.dim`, `.data/`, `.snaphu/`, `Phase_ifg_*.hdr` | тяжёлые промежуточные файлы |
| ML-датасеты | `*.npz`, `manifest.json`, `stats.json` внутри processed/output | генерируются из DEM и эталона |
| Модели | `*.pt`, `*.pth`, `models/insar_residual_runs/` | тяжёлые бинарные веса |
| Итоговые отчёты | `reports/vkr_final_artifacts_*` | генерируются заново, могут содержать тяжёлые изображения |
| Локальный runbook | `LOCAL_PIPELINE_RUNBOOK.md` | содержит персональные пути машины |
